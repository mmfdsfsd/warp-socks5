# warp-socks5
warp-socks5 on debian9<br>
使用方法：<br>
<code>bash <(curl -fsSL https://raw.githubusercontent.com/mmfdsfsd/warp-socks5/main/warp-socks5.sh)</code>
<br>
<br>
<code>curl -fsSL -o /opt/warp/wireproxy_monitor.sh https://raw.githubusercontent.com/mmfdsfsd/warp-socks5/main/wireproxy_monitor.sh && 
chmod +x /opt/warp/wireproxy_monitor.sh && 
bash /opt/warp/wireproxy_monitor.sh</code><br>

更换Warp接入的IP方法：<br>
<code>systemctl restart wireproxy</code>
